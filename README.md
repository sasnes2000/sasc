# DeltaUSD

DeltaUSD (dUSD) is a yield-bearing synthetic stablecoin built on BNB Smart Chain. Users can mint dUSD by depositing USDT and redeem it for USDT after the protocol’s holding period. The token price is calculated transparently on-chain using the current price and configurable APR.

## Official contract

- Network: BNB Smart Chain Mainnet
- Chain ID: 56
- Contract name: DeltaUSD
- Contract address: `0x1851302297e318D658829fD94B89D5aE6528CB9e`
- Token name: Delta USD
- Token symbol: dUSD

## Features

- Mint dUSD by depositing USDT
- Redeem dUSD for USDT
- Transparent on-chain pricing
- Configurable APR mechanism
- Defined redemption holding period
- English and Russian interface
- Wallet support for BNB Smart Chain

## Repository structure

- `/frontend` — DeltaUSD DApp frontend
- `/contracts` — smart-contract source code, if included
- `/dapp.config.json` — DApp and contract configuration
